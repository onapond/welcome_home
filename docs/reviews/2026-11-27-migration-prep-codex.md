## 확인한 항목

- **콘텐츠 검사와 영상 주소.** 임시 콘텐츠 사본에서 `CHECK_CONTENT_ROOT=<tmp> node scripts/check-content.mjs`로 기존 콘텐츠와 유효한 영상 예시가 통과했다. 다른 호스트, 숫자가 아닌 Vimeo ID, 형식이 틀린 퍼가기 값, 설교의 `youtube`·`video` 동시 입력은 파일과 필드가 표시된 한국어 오류로 거부됐다. 단독 `youtube`와 빈 이전 필드는 허용됐다. iframe은 검사한 ID와 선택 값으로 고정된 공급자 주소를 조립한다. 옛 Vimeo를 비우는 규칙 ⑱과 새 영상 지원은 양립한다.
- **여섯 묶음의 사진.** 사진첩·소식·일정·영상·설교·찬양에 잘못된 `thumb`을 넣어 모두 거부되는 것을 확인했다. 사진첩에서 경로만 적은 `cover`가 같은 사진의 `thumb`을 물려받았다. 사진첩·영상은 카드와 격자에 작은 사진, 확대와 OG에 원본을 쓴다. 설교는 카드에 작은 사진, 상세 OG에 원본을 쓰고 찬양은 카드에서 외부 영상으로 이동한다. 소식 본문은 원본을 쓴다. 일정은 스키마만 있고 사진을 표시하는 페이지는 없다.
- **영상 경로와 접근성.** 영상 한 건을 넣고 실제 페이지 함수를 호출했다. 정적 매개변수 한 건, 목록·상세 각각의 canonical, sitemap의 두 경로, 상세 OG의 원본 경로를 확인했다. 없는 ID는 404 신호를 냈고 `dynamicParams`는 `false`다. 소식 탭·머리글 메뉴·바닥글에 영상 링크가 있다. 카드의 링크 이름, 격자 버튼과 사진 대체 텍스트, 확대 대화상자의 방향키 처리와 닫은 뒤 초점 복귀는 코드에서 확인했다.
- **글꼴.** CSS의 496개 선언(400·600·700·900 각각 124개)이 디스크의 WOFF2 124개와 일치했다. 모든 파일의 WOFF2 헤더, Latin preload와 CSS의 URL 일치, 익명 교차 출처 설정, 배포 폴더의 저작권 및 SIL OFL 1.1 전문을 확인했다.
- **사진 변환과 최초 계획.** 합성 JPEG 한 장에 GPS와 EXIF 방향 6을 넣어 같은 스크립트로 변환했다. 표시 방향 기준 900×1800에서 본사진 800×1600, 썸네일 240×480이 생성됐고 양쪽 모두 메타데이터 검사를 통과했다. 새가족소개·중보기도에만 있던 URL 두 건은 최초 계획에서 제외됐다. 허용 게시판에서도 참조한 한 건은 허용 게시물의 키로 한 번만 들어갔다. 생성된 본사진·썸네일 키 모두 실제 `mediaPathProblem`을 통과했다.
