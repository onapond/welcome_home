## ③ 미확인

- 대상 커밋의 임시 사본에서 `npm run check:content`, `npx tsc --noEmit`, `npm run lint`, Webpack 프로덕션 빌드가 통과했다. 정적 페이지 1,372개를 생성했고 이후 리디렉션 검사 결과는 `checked 1498 bad 0`이었다. 기본 Turbopack 빌드는 CSS 처리 중 로컬 포트 바인딩 권한 오류로 완료하지 못했다.
- 실제 수집 캐시를 입력으로 `--no-download --replace`를 빈 임시 출력 폴더에 실행했다. 생성한 콘텐츠 1,500개와 PDF 141개는 대상 커밋과 파일명·바이트가 모두 일치했다. 새 다운로드의 오류 처리는 로컬 응답 대역으로 확인했다. 옛 사이트의 현재 HTTP 응답은 미확인이다.
