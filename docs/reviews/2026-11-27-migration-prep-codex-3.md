## ③ 미확인

기본 `npm run build`의 Turbopack은 CSS 처리 중 로컬 포트 바인딩 권한 오류로 끝났다. 이 환경에서 기본 빌드를 새로 성공시키지는 못했다. `next start`도 127.0.0.1:3125 바인딩이 거절되어 HTTP를 통한 표본 curl 대신 GET 핸들러의 응답과 빌드 HTML을 검사했다. Chromium은 macOS 샌드박스 초기화 단계에서 종료됐다. 따라서 모바일 화면에서 선의 실제 위치, 글자 뒤 픽셀의 최저 대비, LCP 실측값은 미확인이다. 운영 배포·CDN 캐시 적중·실제 함수 호출량도 측정하지 않았다.
