- **화면 동작의 코드 경로.** 영상 상세의 최초 정적 HTML에 iframe이 없고, 재생 버튼은 기본 HTML 버튼이다. 재생 시 공급자 주소의 기존 쿼리를 보존해 자동 재생 옵션을 더하고 iframe으로 초점을 옮긴다(`src/components/features/VideoFacade.tsx:25`). 공유 취소·복사·실패 안내는 각각 처리한다(`src/components/features/ShareButton.tsx:25`). 두 양식에서 처리방침을 열 수 있고, 방문 폼은 칸별 설명과 첫 오류 초점을 연결한다(`src/components/features/VisitClient.tsx:220`, `:287`). 본문 바로가기 대상은 초점을 받을 수 있다(`src/app/layout.tsx:80`). 모바일 바의 하단 여백, 메뉴·입력 포커스 때 숨김, 메뉴를 닫은 뒤 초점 복귀를 확인했다(`src/app/globals.css:227`, `src/components/layout/MobileNav.tsx:33`). 길찾기는 현재 설정에서 인코딩한 도로명 주소 검색으로 연결된다(`src/lib/directions.ts:17`).
- **한국 시간.** UTC 11월 28일 15:05가 KST 11월 29일 일요일 00:05로 계산됐고, 주일 11:00 시작 시각에는 다음 주일로 넘어갔다. 히어로는 대표 예배를 선택해 서버와 첫 클라이언트 렌더에서 같은 정적 요일을 쓴다(`src/components/sections/HeroSection.tsx:10`, `src/components/sections/HeroSlider.tsx:45`).

## ③ 미확인

기본 Turbopack 빌드는 CSS 처리 중 로컬 포트 바인딩이 거절됐다. 별도 사본의 Webpack 빌드는 통과했지만 Turbopack 경고 해소와 해당 번들 추적 결과는 미확인이다. Chromium도 운영체제의 Mach 포트 권한 거절로 시작하지 못했다. 따라서 실제 브라우저의 하이드레이션, 390px에서 메뉴·공유·영상의 키보드 조작, 화면 키보드·고정 바 가림과 초점 표시, 지도 앱 목적지 도착, 외부 영상 실재생, 메일 수신 및 운영 응답 헤더는 미확인이다.
