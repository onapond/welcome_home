- 이전 주보 PDF는 지금 머리말이 실제로 연결한 정상 PDF만, `legacy.seq`로 찾아 다시 쓴다. 연결 기록이 없는 남은 파일은 쓰지 않는다(`--replace` 없으면 경고 뒤 남김).
- 이번 실행에서 받지 못한 옛 PDF만, 이전 연결 사본을 `<crawl>/weekly-pdf/` 캐시로 되돌려 쓴다(변환기가 원래 쓰는 캐시 · 실행이 중간에 실패해도 남음). 머리말은 이 변환기 · `content/README.md`가 쓰는 한 줄 형식만 읽고, `pdf` · `legacy.seq`가 다른 형식이면 아무것도 지우기 전에 멈춘다.
- PDF 완결성 = `%PDF-` 시작 + 끝의 `startxref N %%EOF` + N 위치에 `xref` 또는 `/Type /XRef` 스트림 객체. 판독기(pdfinfo 등)는 의존으로 넣지 않는다.
- 같은 주 묶음은 옛 주차 키(연-월-주), 옛 주소가 없는 새 주보는 같은 날짜끼리.
- 시각은 문구 전체가 한 시각일 때만 읽는다(「오전/오후 H:MM」 · 「오전/오후 H시 (M분)」 · 「HH:MM」).
- 복구 사본은 만들 때 `state.json`에 크기를 바로 기록한다(오프라인 실행에서도). 다음 실행은 그 기록으로 사본을 받아들인다.
- PDF 구조 판독은 이 변환기 안의 가벼운 검사다. 완전한 PDF 파서 수준을 요구하지 않는다 — 실제 주보 141개와 캐시 142개가 통과하고, 지난 판정의 손상 표본이 걸러지면 된다.
- 주보 머리말의 최상위 줄은 따옴표 없는 `key: value`만 받는다. 다른 최상위 줄(따옴표 키 · `? key` · 맨 앞 목록 등)은 멈춘다 — 저장소의 주보 141개는 모두 이 형식.
