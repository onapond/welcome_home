4. **낮음 · 글을 일주일 뒤 올리면 같은 설교의 편집본이 있어도 실황을 남긴다.** `scripts/migrate/youtube_match.py:120`. `media_1/559` 「꿈꾸는 어른아이」의 게시일은 2026-05-10이다. 연결된 실황과 편집본은 모두 5월 3일, 전홍균 목사, 같은 제목이다. 편집본 `cU16vfQC4cE`(31분 19초)은 게시일보다 7일 앞서서 후보에서 탈락한다. `media_1/529` 「저는 구원받았습니까?」도 2025-09-21 게시, 9월 14일 예배여서 `YSBA2OqSOAU`를 놓친다(`channel-durations.tsv:63`, `:128`). 함수가 이미 받는 실황 ID로 실황 제목의 예배일을 조회하고, 설교 제목·설교자까지 일치할 때 사용한다. 같은 날 다른 설교가 있는 경우를 위해 날짜 허용 범위를 일괄 확대하지 않는다.

5. **낮음 · 짧은 설교 제목은 성경 본문 표기가 붙으면 같은 날 편집본도 탈락한다.** `scripts/migrate/youtube_match.py:82`, `scripts/migrate/youtube_match.py:130`. `vimeo-match.tsv:12`의 `media_1/280` 「초막절」은 실황으로 연결된다. 같은 날의 편집본 `35rBrWNE8Bs`(41분 19초, `channel-durations.tsv:371`)은 설교자와 본문 요한복음 7:37–44까지 원글과 같다. 정규화 뒤 「초막절」은 세 글자라 부분일치 기준에서 빠지고 본문 표기 때문에 점수가 0.40으로 내려간다. 영상 제목에서 설교명과 성경 구절을 나눠 비교하고 예배일·설교자·본문을 확인 근거로 쓴다.

6. **낮음 · 다른 편집본도 만점을 받아 채널 목록 순서가 결과를 바꾼다.** `scripts/migrate/youtube_match.py:82`, `scripts/migrate/youtube_match.py:112`. `vimeo-match.tsv:216`과 `:217`의 캄보디아 단기선교 **스케치**에는 현재 맞는 7분 38초 영상이 연결돼 있다. 그런데 같은 해의 일반 단기선교 영상(12분 53초)도 1.00점이다. 후보 순서를 바꾸면 두 글 모두 일반 영상에 연결된다(`channel-durations.tsv:379`, `:380`). 완전히 일치하는 제목을 부분일치보다 우선하고 행사·부서·회차·편집 종류가 다르면 동점을 자동 확정하지 않는다.
