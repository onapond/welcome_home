### 확인한 범위

- 설치된 도구로 TypeScript 검사와 ESLint를 실행해 모두 종료 코드 0을 확인했다. 콘텐츠 로더로 현재 설교 5건, 공지·소식 5건, 주보 5건, 갤러리 2건, 찬양 2건, 일정 1건과 페이지 YAML 7종을 읽었다. 일정 1건은 검토 중 로더를 **별도로 호출한 결과**다.
- 규칙 ⑧⑩⑪. 상세 경로 4종 모두 `generateStaticParams`와 `dynamicParams = false`를 사용한다. 기존 정적 HTML 28개의 canonical·단일 main·내부 링크·앵커를 대조했고 sitemap 경로 집합도 28개와 일치했다. 컬렉션은 날짜 내림차순, 동률이면 ID 내림차순이고 공지는 고정 항목이 먼저다. 설교·소식의 정적 하위 경로와 충돌하는 파일명은 거부한다.
- 요청 ⑥⑦. 실제 폼 핸들러를 외부 통신과 환경변수가 없는 프로세스에서 각각 호출했다. 허니팟 200, 필수값 누락 400, 메일 미설정 503, 같은 인스턴스에서 발송 한도 초과 429를 확인했다. 레이트리밋은 인스턴스 메모리 단위다. Markdown 본문의 원본 HTML은 텍스트로 이스케이프됐다. 공개 페이지에 ISR 설정이나 주기적인 서버 폴링은 발견되지 않았다.
- 규칙 ①②⑫⑬⑭⑮⑰⑱⑳. 제품 소스에서 금지 아이콘·스톡 서비스·Vimeo·framer-motion 사용이 발견되지 않았다. 사진 미지정 분기에는 자리표시가 있고, 기본 요소 스타일은 `@layer base` 안에 있다. 히어로 표어·CTA는 초기 HTML에 있고 어두운 헤더는 투명 로고를 사용한다. 제품 소스·패키지·잠금 파일에 Sanity 런타임 의존이 없으며 범위 내 커밋 9개의 제목은 역할 형식을 따른다.

### 미확인

- 현재 커밋의 새 프로덕션 빌드와 GitHub Actions 실행 결과. 위 HTML·sitemap 검사는 작업 트리에 이미 있던 산출물 기준이다. `HANDOFF.md:59`의 35페이지 빌드는 이전 실행 기록이다.
- 실제 브라우저 화면, 반응형·키보드 동작, Lighthouse 점수. 이 세션에서는 로컬 미리보기 서버의 포트 열기가 실행 환경에서 거부됐다.
- 실배포의 R2 접근·이미지 사용량·요금, 메일 실발송, DNS·Vercel 환경 및 배포 이력(규칙 ⑨⑲). 비밀값과 환경 파일의 내용은 열지 않았다. Git 추적 파일명으로 확인한 환경 파일은 예시 2개이며, 저장소 전체 이력의 비밀값 유무는 미확인이다.
