# m6 확인 — Codex 판정 요청서 (2026-11-27)

## 무엇을 보나

옛 사이트(chungpa21.org) 이전 결과가 **옛 원본과 같은지** 독립적으로 대조한다. 코드 변경은 없다. Claude의 확인 결과는 `docs/migration-plan.md` 6번(m6)에 있다 — 그것을 믿지 말고 직접 표본을 뽑아 본다.

## 자료

- 옛 원본(읽기만): `../chungpa21-crawl/boards/*.json` — 글마다 `seq` · `title` · `date` · `body_text` · `body_html` · `images` · `videos`
- 사진 목록: `../chungpa21-crawl/media/manifest.json` (`photos` · `failures`)
- 새 콘텐츠: `content/{sermons,praise,albums,videos,events,news,bulletins}/*.md` — 머리말 `legacy: { board, seq, url }`로 옛 글과 짝지음
- 빌드 결과(이미 빌드됨 · 다시 빌드하지 말 것): `.next/server/app/**.html` — 사진 주소가 `http://127.0.0.1:4100/<키>`로 들어 있다
- 변환 규칙: `docs/migration-plan.md` · `docs/검토규칙.md` ⑱(Vimeo 비움) · ㉑(판정 기준) · `scripts/migrate/README.md`

## 볼 기준

1. 게시판마다 무작위 5건 이상(설교 `media_1` · `media_2`, 앨범 `s_board_1`, 영상 `s_board_3`, 소식 `s_board_6`, 일정 `s_board_5`, 주보 `weekly`) — 새 페이지 HTML에서 제목 · 날짜 · 본문 글 · 사진 수 · 유튜브 영상 ID가 옛 원본과 맞는가. 다른 것은 의도한 변환(전화번호 가림, 집 주소 `(주소 생략)`, IP · 작성자 아이디 버림, Vimeo 비움, 중복 사진 건너뜀)인지 구분한다.
2. 글 · 사진이 **빠지거나 다른 글에 붙은** 경우가 있는가(짝 맞춤 오류).
3. 본문 HTML이 깨지는가(태그가 글자로 보임, 표 · 줄바꿈 소실, 사진 순서 뒤바뀜).
4. 주보: 옛 주 하나의 PDF가 모두 그 주 페이지들에 있고 PDF 파일이 `public/bulletins/`에 있는가.

## 판정

`docs/검토규칙.md` ㉑을 따른다 — 사이트 코드 · 콘텐츠 문제는 심각도(높음 · 중간 · 낮음)를 붙이고, 중간 이상이 있으면 「고칠 것 있음」, 없으면 「통과」. 본 표본(게시판 · seq)을 결과에 모두 적는다.
